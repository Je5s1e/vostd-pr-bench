## 最核心的经验

normal_lock_new_allocated_node 要求父 PTE token 来自同一实例、键是父节点、对应偏移 alive，且记录的物理地址等于新节点地址。并发模型中逻辑节点位置和实际分配身份都重要；该 PR 还建立具体树到原子模型的精化框架，但新增的归纳与精化义务仍需逐项完成。
