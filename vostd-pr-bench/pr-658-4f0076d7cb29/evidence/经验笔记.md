# PR #658：ManuallyDrop 必须同时阻止真实析构并保留可取回的线性义务

第 595 / 847 项 · 所有权与生命周期 · 归档状态 `MERGED` · 2026-07-20

原题：fix: Redesign `TrackDrop`

## 最核心的经验

重设计使用 core::mem::ManuallyDrop<T> 保存执行值，并在包装中持有 Tracked<T::Obligation>，而不是 new 时立刻消费义务。否则要么 Rust 的 drop glue 仍释放字段，要么逻辑上无法再合法析构。运行时生命周期与 proof 资源都必须对应，不能只修其中一侧。

+}

 impl<T: TrackDrop> ManuallyDrop<T> {
