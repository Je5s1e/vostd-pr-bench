# PR #703：先写外部契约可以分步推进，但必须区分规约与已验证实现

第 636 / 847 项 · 可信边界 · 归档状态 `MERGED` · 2026-08-12

原题：prove: util::range_alloc with 4 external bodies

## 最核心的经验

RangeAllocator 被纳入验证并添加管理范围视图，四个操作仍标记 external_body。成功结果落在管理范围的契约是接口承诺，不是分配算法已证无重叠或回收安全；审查也明确没有核查这些外部契约。后续工作应验证函数体与锁内空闲表不变量。

## 精简例子

```diff
     pub const fn fullrange(&self) -> &Range<usize> {
         &self.fullrange
     }
 
     /// Allocates a specific kernel virtual area.
+    #[verifier::external_body]
+    #[verus_spec(res =>
+        requires allocate_range.start < allocate_range.end,
+        ensures
+            res is Ok ==> (self@.start <= allocate_range.start
+                && allocate_range.end <= self@.end),
+    )]
```
