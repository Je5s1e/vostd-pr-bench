# PR #178：让并行模式显式提示日志交错，避免误读结果

第 170 / 847 项 · 验证工程 · 归档状态 `MERGED` · 2025-08-06

原题：Add warning for parallel verification

## 最核心的经验

这个小 PR 将并行验证输出乱序的事实直接展示给使用者。形式化工具的可用性不只是运行速度，还包括用户能否正确归属失败信息；并行运行时应以目标级结果判断成功，而不是从终端最后出现的一条绿色消息推断所有目标都通过。
