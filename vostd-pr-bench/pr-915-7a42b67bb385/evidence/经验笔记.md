原题：Verify bzImage address mappings

## 最核心的经验

bzImage 的 SetupVA 与文件偏移建立精确转换关系，但执行体仍 assume 正常 setup ELF 地址及偏移落在可加减范围。经验是将可信构建流水线输入与任意畸形文件区分；模块在 Linux host target 验证，不能把内核 bare-metal 目标的环境直接沿用。
