# PR #171：节点逻辑删除后，其物理地址未必已可重新分配

## 最核心的经验

RCU 模型增加 free_paddrs 及其与 strays 不相交的关系，修正树中没有 nid 就能在任意 paddr 分配的漏洞。等待回收的旧节点仍占用地址身份；分配必须消耗真实空闲资源。讨论还指出 CPU token 的域必须覆盖所有合法 CPU，而不只是已有键合法。

## 精简例子

```diff
+
+    #[sharding(set)]
+    pub free_paddrs: Set<Paddr>
 }
 
 #[invariant]
 pub fn wf_nodes(&self) -> bool {
-    self.nodes.dom().all(|nid: NodeId| NodeHelper::valid_nid(nid))
+    &&& self.nodes.dom().all(|nid: NodeId| NodeHelper::valid_nid(nid))
+    &&& self.nodes.dom().finite()
 }
 
```
