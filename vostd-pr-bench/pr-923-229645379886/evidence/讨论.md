## PR正文 · YuQuuu · 2026-11-12T19:59:29Z

[原文](https://github.com/asterinas/vostd/pull/923)

Enable `mm::heap::slot` and `slot_list` in place and verify ten existing functions. Prove empty construction, LIFO push/pop, exclusive slot ownership transfer, preservation of remaining links, and exact slot address/type/size and physical-address conversion.

Keep the `usize` link representation, using existing vstd permission-aware reads/writes and provenance helpers to verify memory access. Runtime behavior is preserved. Slab allocation, large alloc/dealloc, and the global allocator remain disabled.

Overlaps #505 in scope; implemented independently from main without its external raw-pointer read/write specifications.
