# PR #146：分配接口应同时提供新鲜性、初始化和元数据关系

第 138 / 847 项 · 所有权与生命周期 · 归档状态 `MERGED` · 2025-07-30

原题：Alloc if none

## 最核心的经验

alloc_if_none 拆出分配返回的 Tracked 权限，先确认已初始化及新地址尚未存在于当前帧集合，再连接新孩子的层级。只有“返回了一个地址”不足以验证插入；需要一个与权限、分配器和对象元数据相协调的契约，并逐项保持旧状态中未受影响的关系。
