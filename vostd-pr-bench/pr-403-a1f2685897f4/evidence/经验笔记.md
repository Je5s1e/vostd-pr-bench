# PR #403：从指针导出地址，避免维护两个可能不一致的身份字段

原题：Remove `addr` field in `ReprPtr`

## 最核心的经验

ReprPtr 删除 addr 缓存字段，统一从 ptr.addr() 获取地址，并提供明确的逻辑转换。资源关联应尽量有单一身份来源，否则每次构造和变更都要额外证明两字段相等；同一 PR 用借用替换 take/put 公理是另一条改进线，但部分借用包装当时仍为 external_body。

## 精简例子

```diff
     fn from(ptr: PPtr<R>) -> Self {
-        Self { addr: ptr.addr(), ptr: ptr, _T: PhantomData }
+        Self { ptr: ptr, _T: PhantomData }
+    }
+}

+        true

```
