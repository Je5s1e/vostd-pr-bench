## PR正文 · rikosellic · 2026-04-13T07:06:24Z

[原文](https://github.com/asterinas/vostd/pull/403)

The `addr: usize` field in `ReprPtr` does not provide any new information, as the `ptr: PPtr` field already has an `addr` method that produces a `usize`. This PR deletes this field, saves a bit line, and it may be easier to migrate if Verus supports `dyn` better in the future. @SNoAnd, do you think this change is okay?
