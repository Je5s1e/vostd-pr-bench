[原文](https://github.com/asterinas/vostd/pull/492#discussion_r3339110119)

verified_bitflags/src/lib.rs · 行 109 · 原行 109 · 已解决；已过时

```diff
@@ -105,7 +105,7 @@ macro_rules! bitflags {
                     }
                     Self {
                         bits: self.bits,
-                        flags: self.flags,
+                        flags: Ghost(Self::flags_from_bits(self.bits)),
                     }
```

`Clone::clone` constructs the `flags` field using an unqualified `Ghost(...)` constructor and calls `flags_from_bits` unconditionally. Because this macro expands in downstream crates, `Ghost` may not be in scope at the invocation site, and the unconditional `flags_from_bits` use can reintroduce the doc/non-`verus_keep_ghost` build failure that `from_bits_unchecked` is already guarding against. Prefer fully-qualified `::vstd::prelude::Ghost` and mirror the same cfg-gated initialization used in `from_bits_unchecked`.
