# PR #182：把不同转换共享的保持性证明提炼为参数明确的引理

第 174 / 847 项 · 证明组织 · 归档状态 `MERGED` · 2025-08-08

原题：Clean and stablize proofs

## 最核心的经验

RCU 分配与释放包含重复的树路径和 stray 关系推导；本 PR 将这些内容收敛到专门的 keep-invariant 引理。复用应以真实变化范围和前后关系为参数，而不是复制长证明块；这样同一模型修正可以在一处传播，也更容易检查每个转换是否满足引理前提。
