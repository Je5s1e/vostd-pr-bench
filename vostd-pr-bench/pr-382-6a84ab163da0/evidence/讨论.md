## Pull request overview

This PR updates Verus specifications and proofs across the MM/page-table code to eliminate `admit()` usage, mainly by strengthening pre/postconditions and adding lemmas that connect page-table metadata to entry-owner invariants.

**Changes:**
- Strengthen mapping preconditions in `VmSpace`/page-table cursor specs (including region/metadata constraints) and remove `admit()`-based assertions.
- Improve huge-page split proof in `Entry::split_if_mapped_huge` by adding lemmas (`last_pte_implies_frame_match`, `huge_frame_split_child_at`) and tightening `EntryOwner` invariants.
- Refine PTE “absent” properties (e.g., absent entries are not `last` for levels > 1) and make `UserPtConfig::item_into_raw_spec` concrete.
