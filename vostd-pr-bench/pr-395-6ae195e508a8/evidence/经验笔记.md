## 最核心的经验

RwMutex::try_upgrade 为成功的写权限、失败时重新返回的升级守卫以及撤回 token 分别记账。验证带等待的锁不能只证明原子交换成功：失败、重试、降级和 Drop 的执行顺序都要保持同一资源协议；互斥安全也不自动证明等待最终结束。
