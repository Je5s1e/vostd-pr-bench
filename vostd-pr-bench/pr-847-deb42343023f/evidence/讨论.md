## PR正文 · DID-Lab-SZU · 2026-10-22T02:20:23Z

[原文](https://github.com/asterinas/vostd/pull/847)

Mount the RISC-V architecture in the verification build alongside x86 and add the specification instance that the shared address-space model needs.

- Mount `irq`, `mm`, and `timer` for `riscv64` and select the `RiscvArch` specification instance through `CurrentArch`.
- Export the Sv48 paging constants and implement `PagingConstsTrait` with the same spec and exec layout as x86.
- Add verified `PageTableEntry` operations and the `PageTableEntryTrait` implementation, including flag parsing and the `is_last` mask rewrite avoids Verus's BitOr specification dependency-order issue.
- Add `ostd/specs/arch/riscv` with the address-space model and the transitional `lemma_arch_specific_consts_properties`, which still depends on the shared `axiom_current_paging_consts_hardcoded`.
- Add `riscv64imac-unknown-none-elf` and `loongarch64-unknown-none-softfloat` to `rust-toolchain.toml`, and update the RISC-V `timer` and `task` items shared with `cpu` and `kvirt_area` to build on that target.
