## 普通评论 · rikosellic · 2026-03-23T03:10:58Z

[原文](https://github.com/asterinas/vostd/pull/350#issuecomment-4107705907)

@hiroki-chen If you mean `Arc` from Rust std, you do not need any extra method to access its value in spec mode. Verus has special treatment for `Rc`, `Arc` and `Box`, which allows you to do things like this:
```
use vstd::prelude::*;
use std::sync::Arc;

verus!{
    
    fn main(){
        let p = Arc::<usize>::new(5);
        assert(p==5);
    }
}
```
