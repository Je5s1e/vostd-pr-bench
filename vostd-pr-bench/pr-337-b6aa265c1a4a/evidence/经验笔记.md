# PR #337：把底层 guard 抽象成外部类型是集成手段，不是实现验证

第 316 / 847 项 · 可信边界 · 归档状态 `MERGED` · 2026-03-06

原题：Add Guard traits without implementation and make rwarc verifiable.

## 最核心的经验

零变体 PreemptDisabled 通过 external_type_specification 接入，disable_preempt 等函数仍为 external_body，部分实现暂用 unimplemented。这样能让上层 RwArc 继续建模，但必须记录抢占、中断和调度行为尚由外部假设提供，不能将“可验证的接口骨架”称为完整系统保证。
