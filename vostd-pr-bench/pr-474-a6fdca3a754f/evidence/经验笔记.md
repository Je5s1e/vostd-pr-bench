# PR #474：禁止抢占守卫的生命周期必须来自真实借用，而不是调用者任意指定

第 433 / 847 项 · 所有权与生命周期 · 归档状态 `CLOSED` · 2026-05-24

原题：Try to use `dyn InAtomicMode`

## 最核心的经验

将 InAtomicMode 改成 dyn trait 并不能解决守卫模型的寿命问题。讨论发现 disable_preempt 的局部返回对象被赋予用户选择的寿命，甚至使用 static 的 tracked 守卫；证明应把资源可用期绑定到真实 guard 的借用与销毁，不能靠擦除寿命或改写参数语法绕过。
