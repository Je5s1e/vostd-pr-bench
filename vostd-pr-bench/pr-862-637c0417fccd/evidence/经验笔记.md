# PR #862：集合整体性质不能放在可能为空的逐元素量词内部

第 786 / 847 项 · 规约与模型 · 归档状态 `MERGED` · 2026-10-25

原题：Fix empty-set partition specification

## 最核心的经验

is_partition 原先把不交与覆盖条件放进对 parts 的 forall，空 parts 时它们全部真空成立，甚至允许分割非空集合。修复把 pairwise_disjoint 和 s == parts.flatten() 放到外层，并证明空分区族当且仅当 s 为空。审查规格时必须主动检查空集、零长度和不存在见证的边界。

## 精简例子

```text
错误：forall p in parts: 局部条件(p) && 整体覆盖条件。正确：(forall p in parts: 局部条件(p)) && 整体覆盖条件。
```

概念示意，非经过验证的 Rust/Verus 程序。原始变更锚点：
