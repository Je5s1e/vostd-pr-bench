# PR #518：空值构造应属于可空类型，而不是破坏非空类型的含义

第 474 / 847 项 · 规约与模型 · 归档状态 `MERGED` · 2026-06-12

原题：Rcu fix

## 最核心的经验

RCU 修复恢复 RcuOption::new_none，并保留 Rcu 与 RcuOption 的职责区分。执行表示虽然共用 RcuInner，公开类型仍应准确表达是否允许空值；内部 ghost 初始化模式的修复不能顺手删掉原可空 API，也不能让非空 Rcu 获得不符合语义的构造路径。
