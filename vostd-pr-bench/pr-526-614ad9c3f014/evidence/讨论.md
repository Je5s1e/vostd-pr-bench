## Pull request overview

This PR replaces previously global page-table “axioms” with per-`PageTableConfig` proof lemmas and threads those lemmas through the virtual-address range arithmetic, so key bounds and bit-shift facts are proven from configuration-specific assumptions rather than assumed globally.

**Changes:**
- Added `PageTableConfig` proof requirements for top-level index range bounds and the relationship between `LEADING_BITS` and “high-half” sign-extension.
- Reworked `vaddr_range` helper arithmetic (`pt_va_range_start/end`, `sign_bit_of_va`) to be internally verified, supported by new proofs in `vaddr_range_proofs.rs`.
- Updated page-table node meta proofs to use the new per-config lemmas instead of the removed global axioms.
