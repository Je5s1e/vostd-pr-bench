## Specs and properties supplemented by the ktest verification

### 1. New proof function in the specs layer (`ostd/specs/mm/io.rs`)

| Addition | Purpose |
|---|---|
| `VmIoOwner::tracked_shrink_range_front(nbytes)` | Shrinks the owner's range to its front `nbytes` bytes, preserving `id` / `is_kernel` / `is_fallible` / `mem_view` plus the three view-predicate implications — so the caller's `wf` relation survives a `limit` of the window (both limit tests rely on it) |

### 2. Contract additions in `mm::io` (`ostd/src/mm/io.rs`)

| API | Properties added |
|---|---|
| `VmWriter::from` / `VmReader::from` (reshaped from the `From` trait during the migration) | Full owner out-param contracts: `inv`, `wf(owner)`, view kind (write_view / read_view_initialized), `cursor.range == owner.range`, `owner.range.len == slice.len()`, kernel bounds (gated with `len == 0 \|\|` for the empty-slice case) |
| Infallible `write_val` | `avail >= size_of::<T>() ==> r is Ok` (kernel-space writes cannot fault); `avail < size_of::<T>() ==> r == Err(InvalidArgs)`; `final(owner).has_write_view()` (unconditional); the Err branch pins both `*self` and `*owner` |
| Infallible `read_val` | Same family: bidirectional Ok/Err conditions, `final(owner).read_view_initialized()`, Err branch pins both `*self` and `*owner` |
| Infallible `read_once` | Short-read `==> Err(InvalidArgs)` row plus Err-branch double pinning |
| Fallible `write_val` / `read_val` | Sufficient condition for the shortfall direction: `==> r == Err(InvalidArgs)` |
| `has_remain` / `has_avail` | `returns remain_spec() > 0` / `avail_spec() > 0` (exact boolean) |
| `limit` (reader and writer) | Exact value `== (if old <= max { old } else { max })` |
| `to_fallible` (reader and writer) | Symmetric `requires self.inv()` / `ensures r.inv()` |

### 3. Rustdoc / contract alignment

`read_val`'s Verified Properties section now states what the contract actually
delivers instead of promising a nonexistent `val_owner` — the documented root
cause of why the original value assertions could not be restored.
