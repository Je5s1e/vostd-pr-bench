# PR #782：始终成立的容器结构边界可用类型不变量，简化每个 API 的前提

原题：prove: boot::memory_region::Deref

## 最核心的经验

MemoryRegionArray 的 count <= LEN 从 Inv 转为 type_invariant，使 Deref 可以证明返回有效前缀，push 不再反复传递同一 inv。类型不变量适用于构造和每次可观察更新都保持的结构条件；不能把持锁期间允许暂时破坏的关系也机械搬入其中。

## 精简例子

```diff
 
 verus! {
 
-impl<const LEN: usize> Inv for MemoryRegionArray<LEN> {
-    closed spec fn inv(self) -> bool {
+impl<const LEN: usize> MemoryRegionArray<LEN> {
+    #[verifier::type_invariant]
+    closed spec fn type_inv(self) -> bool {
         self.count <= LEN
     }
 }
```
