# PR #656：抽象状态未变化的操作，不必保留一层无效果的可信包装

第 593 / 847 项 · 规约与模型 · 归档状态 `MERGED` · 2026-07-20

原题：Prove MM embedding ownership helper axioms

## 最核心的经验

VmReader::limit 的嵌入公理只保证 owner 原样不动，因为执行时改变的是句柄 end 而非该 owner 模型；本 PR 删除这类空壳，并将 CursorEntry 构造改为 proof。简化时仍须明确模型未表达什么，恒等 owner 操作并没有验证容量截断的完整功能语义。

## 精简例子

```diff
 
-/// Mirror of [`crate::mm::io::VmReader::limit`].
-///
-/// Exec only mutates the handle's `end` field (no owner mutation), so
-/// owner state is fully preserved.
-pub axiom fn vm_reader_limit_embedded(tracked owner: &mut VmIoOwner, max_remain: usize)
-    requires
-        old(owner).inv(),
-    ensures
-        final(owner).inv(),
-        *final(owner) == *old(owner),
-;
```
