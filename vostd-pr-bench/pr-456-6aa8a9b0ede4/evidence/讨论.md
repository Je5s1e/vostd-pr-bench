The `is_cache_coherent` flag is now only stored and never acted on. For non-cache-coherent devices, `map(..., false)` no longer switches the linear mapping to uncacheable (nor restores it later), so CPU/device views can become incoherent; please keep the previous cache-policy transition or fail this mapping mode until it is implemented.

## Pull request overview

This PR enables and rewrites `dma_coherent` to add a Verus-style coherent DMA mapping implementation parallel to `dma_stream`.

**Changes:**
- Enables the `dma_coherent` module.
- Replaces the prior `DmaCoherent` implementation with a generic `RwArc`/tracked-owner based implementation.
- Adds `VmIo`, `VmIoOnce`, address accessors, and reader/writer helpers for coherent DMA mappings.
