# PR #855：移除硬编码公理时，要检查是否只是把同一限制搬到了另一层 trait

原题：prove: remove paging layout axiom and refactor architecture specs

## 最核心的经验

开放 PR 将页表布局假设改成配置证明义务，但审查追问这些约束是否仍错误限制不同层数的 IOMMU 等实现。真正泛化需要让每个定理只依赖必要参数；把 axiom 改名或移到 PageTableConfig 不自动证明所有 PagingConsts 实例都支持同一布局。
