## PR正文 · SNoAnd · 2026-04-27T08:15:24Z

[原文](https://github.com/asterinas/vostd/pull/424)

Lots going on in this PR. `PageTableGuard` uses &mut again, which simplifies our ability to check code equivalence. I turned some arithmetic axioms into verified proofs, which had knock-on effects at their call sites as some of them had to be split into different cases.

I used the panic handling changes to improve the `kvirt_area` specs and eliminate unnecessary preconditions, and did the `panic_cond` propagation in the remaining places that I hadn't in the last PR. That's for all of the explicit `panic_cond` predicates, though, I still need to go through `segment.rs` and `io.rs` because some of those functions followed the pattern without obeying the naming convention. The `kvirt_area` fixes also involved more precise modeling of untracked frames.
