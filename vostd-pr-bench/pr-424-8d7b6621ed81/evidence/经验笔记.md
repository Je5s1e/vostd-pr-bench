# PR #424：机器整数截断的等式需要先证明值处于不回绕范围

第 387 / 847 项 · 算术与位运算 · 归档状态 `MERGED` · 2026-04-27

原题：Interrelated arithmetic, &mut porting, and panic handling fixes

## 最核心的经验

地址范围证明先得到 0≤e_pre-1<2^64，再说明取模 2^64 不改变值，取代直接假定截断正确。验证页表地址和符号扩展时，数学整数计算、机器转换与区间合法性应逐层连接；同时返回 &mut 的接口恢复可以减少与原执行代码的偏离。
