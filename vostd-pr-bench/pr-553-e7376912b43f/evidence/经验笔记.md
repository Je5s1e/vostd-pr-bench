# PR #553：由路径不相交推出物理地址不同，需要元数据中的唯一性证据

## 最核心的经验

旧节点明确满足 is_node，并在 regions 中只有自己的路径记录；若子树条目地址与它相同，索引相同便迫使路径记录相同，与路径不相交矛盾。该推导还需子树的 path_correct 性质，不能把路径不同直接公理化为地址不同，更不能推广到允许别名的数据帧。
