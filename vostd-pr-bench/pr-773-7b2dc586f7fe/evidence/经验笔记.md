## 最核心的经验

指南区分 ghost 比较和算术中的冗余转换，与 spec 函数 int 参数、单独除数等仍需明确类型的位置。经验不是全局替换字符串：应逐处确认表达式仍在所需的数学整数域，执行代码中的截断或溢出语义更不能随证明格式清理而改变。
