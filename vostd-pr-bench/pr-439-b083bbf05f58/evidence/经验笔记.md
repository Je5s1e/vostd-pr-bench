# PR #439：元数据内部权限应有唯一持有处，避免随容器复制

第 402 / 847 项 · 所有权与生命周期 · 归档状态 `MERGED` · 2026-05-08

原题：Bring segment.rs back into alignment with original

## 最核心的经验

SegmentOwner 改为保存各帧的槽位指针权限，内部字段权限则专属 regions.slot_owners[idx].inner_perms。段、链表和全局区域若各持一份可写内部权限，会破坏排他性；应明确谁拥有、谁借用，并在错误分支归还临时取出的资源，而不是只恢复执行游标。
