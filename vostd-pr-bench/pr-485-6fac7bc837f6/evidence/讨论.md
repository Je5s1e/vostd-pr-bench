## PR正文 · SNoAnd · 2026-06-01T08:54:32Z

[原文](https://github.com/asterinas/vostd/pull/485)

This PR verifies `PageTablePageMeta::on_drop` and `cursor_mut_at`. Required the change I mentioned in PR 454, removing the locally carried, typed slot perms from owner objects and instead keeping them in a `MetaRegionOwners` object at all times. This was a big change, but a good one; the old model made sense when we didn't have good &mut support, but now we can borrow those permissions from `MetaRegionOwners` instead, via `borrow_typed_perm` and `borrow_mut_typed_perm` axioms. This lets us eliminate the excess preconditions on `cursor_mut_at`. It also removes some of the complexity in `on_drop`, where we previously had to collect the permissions for the dropped children separately instead of assuming that they were in `regions`.

I've also simplified the `Guards` structure to carry the set of addresses with corresponding guards. It still carries a lifetime, and the places where we used `'static` are fixed. It no longer needs a `PageTableConfig` parameter, meaning that we don't need separate `Guards` structures for kernel and userspace.
