# PR #500：实现中的地址转换与证明中的索引辅助函数应明确分层

第 457 / 847 项 · 规约与模型 · 归档状态 `MERGED` · 2026-06-03

原题：refactor(mm): consolidate frame meta mapping into specs

## 最核心的经验

frame_to_meta、meta_to_frame 保留在原执行模块，通过 when_used_as_spec 连接逻辑公式；frame_to_index 等额外桥接留在规格侧。辅助索引让权限模型易于表达，但不应伪装成原内核已有 API。证明往返或单射时，还要明确页对齐和有效地址范围。

```diff
-#[verifier::when_used_as_spec(meta_to_frame_spec)]
-pub fn meta_to_frame(vaddr: Vaddr) -> (res: Paddr)
+/// `frame_to_index` is injective on page-aligned paddrs.
+pub broadcast proof fn lemma_frame_to_index_injective(p1: Paddr, p2: Paddr)
     requires
-        FRAME_METADATA_RANGE.start <= vaddr && vaddr < FRAME_METADATA_RANGE.end,
-        vaddr % META_SLOT_SIZE == 0,
+        p1 % PAGE_SIZE == 0,
+        p2 % PAGE_SIZE == 0,
+        p1 != p2,

```
