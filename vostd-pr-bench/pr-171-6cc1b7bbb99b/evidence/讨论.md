The invariant is wrong. 
Every node has a stray flag, which is stored in the corresponding metaslot. The stray flag indicates whether the node exists in the page table. True implies the node is removed and waiting for recycling. False implies the node is in the page table.
The rcu tree spec model node states of a page table. Thus, every page table node should have a false stray flag. Also,  the paddr stored in the stray enum should be consistent with the address of the node. 
I think `inv_pte_is_alive_implies_stray_has_false` and `inv_stray_has_false_implies_pte_is_alive` are enough to describe these properties.

## 普通评论 · Xungan2 · 2025-08-04T08:32:39Z

[原文](https://github.com/asterinas/vostd/pull/171#issuecomment-3149637962)

You remind me that the cursor mechanisms of rw and rcu are different. The `inv_non_overlapping` essentially guarantees that all write-locked nodes should be exclusively owned. Compared with the rw version, if the cursor of rcu is in state `Locking(nid1, nid2)`, then all nodes between `[nid1, nid2)` are write-locked. So we should make some changes to `inv_non_overlapping`.
