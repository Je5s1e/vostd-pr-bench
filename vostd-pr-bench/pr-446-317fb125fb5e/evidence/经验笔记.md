# PR #446：为标准 trait 增加环境前提时，要明确接口已经发生变化

第 409 / 847 项 · 规约与模型 · 归档状态 `MERGED` · 2026-05-12

原题：Add `default` interface for `VmSpace`

## 最核心的经验

VmSpace::default 需要区域与守卫等 tracked 参数及区域不变量，而原 Default::default 无法承载当时所需契约，因此转为成员函数。验证适配可以选择这种方案，但必须注明原 trait 入口的差异，不能让用户以为普通泛型 Default 调用已经得到同样保证。

## 精简例子

```diff
 #[verus_verify]
 impl<'a> VmSpace<'a> {
+    #[inline]
+    #[verus_spec(r =>
+        with Tracked(regions): Tracked<&mut MetaRegionOwners>,
+            Tracked(guards_k): Tracked<&mut Guards<'static, KernelPtConfig>>,
+            Tracked(guards_u): Tracked<&mut Guards<'static, UserPtConfig>>,
+        requires
+            old(regions).inv(),
+    )]
+    #[allow(private_interfaces)]
+    pub fn default() -> Self {
```
