Well, there could be two ways:

- Convert unsupported traits into member functions but this requires some code changes.
- Use `ExTrait` and add a spec impl glue so that we can specify preconditions/postconditions but this might not be general for all cases and sometimes unstraightforward.

I chose to avoid the second one since sometimes Verus has a spec layer for `ExDefault` that forbids us to declare another one
