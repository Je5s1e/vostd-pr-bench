## 最核心的经验

默认流程改用 cargo verus，而文档目标的依赖从 verify 变成 build。命令名称相近不代表检查内容相同：应明确验证、编译、文档生成和依赖跳过的各自职责，不能沿用旧版“生成文档必先执行同一验证命令”的说明。

## 精简例子

```diff
 
-doc: verify
+build:
+	cargo dv build
+
+doc: build
 	cargo dv doc --target ostd
 
-verus update:
-	cargo dv bootstrap $(if $(filter update,$@),--upgrade,)
+verus:
+	cargo dv bootstrap
```
