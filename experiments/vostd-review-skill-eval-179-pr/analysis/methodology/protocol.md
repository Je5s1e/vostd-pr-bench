# 评测协议与结果边界

[← 阅读入口](../README.md)

## 被测对象与样本

被测skill为 `vostd-code-review`，原工作区路径为 `vostd-pr-test/.codex/skills/vostd-code-review`。179份报告均提及fast配置，通常跳过穷尽规则清单、历史分析、子agent及验证实验。归档文件和当前副本一致，但缺少完整运行轨迹，不能逐次证明加载版本及执行步骤。

评估单位是179个快照，属于164个PR。244个标签按快照计数，同一PR的多个快照可能相关。原96份含117标签，新增83份含127标签；这是处理批次，不是训练/验证/测试切分。所有快照均有标签，零标签或干净负样本数为0。

## 根因匹配

| 状态 | 定义 | 是否计入严格召回 |
|---|---|---|
| F | 明确指出同一根因或所需的具体证明义务 | 是 |
| P | 仅覆盖具体子义务，或相关问题但范围/政策不完全一致 | 否 |
| M | 未匹配该标签根因 | 否 |
| X | 标签中的before问题已在after修复 | 原始分母保留，敏感性结果剔除 |

同文件、同规则、相近关键词不构成命中。一个原始finding可以含多个明确子声明，分别关联标签；多个finding也可能共同覆盖一个标签。详见[逐条表](../reports/label-matches.md)。

原96份判断来自前次分析，本轮沿用；新增127条由单一agent逐条判断并对关键案例回查源码。未进行独立人工校准。旧历史报告中的“人工”表述不应被引用为独立人工真值认证。

## 指标

- 严格micro recall：F / 全部标签 = 58/244。
- 宽松micro recall：(F+P) / 全部标签 = 65/244；不为P任意赋半分。
- 排除X敏感性结果：58/241；尚未完成全部标签的diff适用范围审计。
- 快照macro：每个有标签快照的严格recall等权平均。
- PR等权macro：先对每个PR内部快照的recall平均，再对PR平均；不是跨快照缺陷去重。
- 类别/机制统计：`category`来自基准；`group`为分析时设计的互斥机制组。规则统计使用标签的`rule_ids`，可以重叠，不能直接相加。
- 分母为0时记录`null`，不默认0或1。

300是**原始报告项数**，尚未完成全量原子化与根因去重。56条完整关联、7条仅部分关联、237条未关联；不能将这些计数当作真实TP/FP，也不能由此推导precision、F1、确认误报/PR或原子未决率。匹配标签不为评论的附带严重后果背书。

## 范围与隔离

`after/`是待审查快照，不保证是修复版；`before/after`不能自动当作bug/fix配对。#403/#499/#862为本次已确认的X；#763虽然标签定位before，问题却是原始代码记录被删除，不能按before字段机械排除。

当前16个样本保留了历史evidence，其中有`core_lesson`提示。是否实际读取未知，见[审计清单](../provenance/input_exposure_audit.json)。此外，#628/#632/#770/#856/#886/#931已在项目说明中列为已暴露案例。移除这六个PR的敏感性统计不等于消除全部泄漏。

本批已经逐标签分析；据此改skill后，本批只能作为开发回归证据。泛化评估应使用新的、依赖分组后隔离且未暴露的数据。没有随机化、重复成对运行或完整预算记录，本包不提供显著性、因果收益或跨仓库泛化结论。
